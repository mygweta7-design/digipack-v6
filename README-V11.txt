DIGIPACK V11 - תיקון דוחות, תוויות ושליחה

מה נוסף:
1. כפתור "שלח דוח עכשיו לבדיקה" במסך מנהל.
2. השליחה האוטומטית עדיין דרך Vercel Cron.
3. השליחה מוגדרת ל:
   - yossi@digipack.co.il
   - renana@digipack.co.il
4. דוח מנהלים מציג קישורי תוויות חו״ג.
5. אם קיימת רשומת תווית אבל אין קישור, תופיע הודעה לבדוק הרשאות Storage bucket בשם labels.

בדיקה אחרי העלאה:
1. להעלות את כל הקבצים ל-GitHub ולעשות Commit.
2. להמתין ל-Deploy ב-Vercel.
3. לפתוח את האפליקציה עם Ctrl+F5.
4. להיכנס כמנהל.
5. ללחוץ "שלח דוח עכשיו לבדיקה".
6. לבדוק אם מתקבל מייל.

אם אין קישורי תוויות:
צריך להיכנס ל-Supabase > Storage > bucket labels
ולוודא שהוא Public, או ליצור Policy לקריאת קבצים.
