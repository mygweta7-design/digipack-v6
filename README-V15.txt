DIGIPACK V15 - תיקון שמירת URL לתוויות

מה תוקן:
1. אחרי צילום תווית, התמונה עולה ל-Supabase Storage bucket בשם labels.
2. כתובת ציבורית נבנית ידנית ונשמרת בעמודת image_url בטבלת material_labels.
3. אם ההעלאה או שמירת הקישור נכשלת, תופיע הודעת שגיאה ברורה.
4. דוח מנהלים ואקסל יציגו את עמודות התוויות.

בדיקה:
1. העלה את כל הקבצים ל-GitHub.
2. Commit changes.
3. המתן ל-Deploy ב-Vercel.
4. פתח את האפליקציה עם Ctrl+Shift+R.
5. צור עבודה חדשה עם צילום תווית.
6. בדוק ב-Supabase > material_labels שה-image_url מלא.
7. בדוח אמור להופיע קישור "פתח".
